# Yonel Cafe & Restaurant — redesign

A complete responsive static website redesign for Yonel Cafe & Restaurant.

## Files
- `index.html` — site content
- `style.css` — styling and responsive layouts
- `script.js` — mobile navigation interaction

## Deploy on GitHub Pages
1. Replace the files in the `Yonel-Cafe-Restaurant` GitHub repository with these three files.
2. Commit the changes to the repository's configured Pages branch.
3. Keep GitHub Pages configured for the repository root.

The site includes illustrative photos and sample copy. Replace photos, location, hours, menu, and contact information with verified business details before publication.
